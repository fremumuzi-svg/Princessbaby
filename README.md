# Baby Princess: Adventures in Corruption — Animation Series

A bold, satirical HTML5 animation series exploring corruption in various systems through the eyes of an 8-pound Chihuahua with a tiara and zero tolerance for nonsense.

## Episodes

1. **EP.1 — ICE ICE SHADY** — Immigration enforcement corruption
2. **EP.2 — LIKE, SHARE & LIE** — Social media algorithm corruption
3. **EP.3 — PILL PUSHERS & PROFIT** — Pharmaceutical industry corruption
4. **EP.4 — BREAKING BAD NEWS** — News media corruption
5. **EP.5 — HOLY HUSTLE** — Religious institution corruption
6. **EP.6 — WORLD GONE WILD** — Political/UN corruption

## Files

- `index.html` — Main gallery page
- `episode.html` — Individual episode player
- `css/style.css` — All styling
- `js/episodes.js` — Episode database
- `js/gallery.js` — Gallery functionality
- `js/player.js` — Episode player
- `animations/` — HTML5 animation files
- `images/` — Thumbnail images

## Character
**Baby Princess**: A small, sassy Chihuahua wearing a sparkling tiara. Catchphrase: *"Bark at the truth, baby!"*
